## 📖 How to Use This Repository

1. Open the Jupyter notebooks in `QS Python` or `Django` with Jupyter Notebook/Lab or VS Code.
2. Open HTML files in `QS WebTech/HTML CSS` directly in a browser.
3. Run JavaScript examples by opening the topic folders in a browser.
4. Import or open SQL scripts in a SQL client to review and practice the queries.
5. For Django projects, activate `Django/myenv` and run the project using `python manage.py runserver` from one of the project directories.

### Django Setup Example

On Windows PowerShell:

```powershell
cd Django
.\myenv\Scripts\Activate.ps1
cd FirstProject
python manage.py runserver
```

Repeat the final steps for `MyProject` or `QSpiders` to run another project.
